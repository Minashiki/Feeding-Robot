# M2 参数说明

刚度、阻尼和速度上限取 M2Plan 第 5.2 节的初值。平移阻尼按等效质量 2 kg、阻尼比 1 得到 49 N·s/m；旋转按 0.02 kg·m² 得到 0.8 N·m·s/rad。这些是仿真调参尺度。

力矩变化率没有沿用方案里的 100 N·m/s。关节 2 的重力偏置约 23 到 36 N·m，从真实零力矩按 100 N·m/s 爬升时，未补偿重力会把关节速度推过 0.5 rad/s。冻结值为 2000 N·m/s，上电保持才能留在速度和 20 mm 偏差门槛内。任务力矩使用同一变化率。

腕部补偿使用编译后的工具子树质量 0.08 kg。`mj_objectAcceleration` 在静止时给出向上的 9.81 m/s²，这是比力；坐标加速度等于该读数加上 `opt.gravity`。减去 `m(g-a)` 后，空载残余在 0.02 N / 0.002 N·m 以内。食物质量不进工具模型，勺上食物会留下约 0.03 N 的载荷。

`hybrid_normal_force.enabled` 为 false。混合法向力没有做三种弹簧的条件验收，不能写成已通过。

工作空间盒子是起始 TCP 周围 50 mm，只覆盖局部测试，不代表完整喂餐空间。
