# M2 参数说明

M2 full-v2 的启动停车补验将独立停车阻尼候选改为 12 N·m·s/rad。零力矩启动后立即 STOP、构型0、A组下，候选8在0.535 s才达到0.02 rad/s，未满足0.5 s；候选12在0.377 s达到并保持。候选16/24/32也通过该诊断，选择首个通过的12继续完整验证。原始诊断见 `outputs/m2/reviews/review-20260926/stop-candidates.json`。这不代表完整矩阵已通过，m3_ready仍由完整验收决定。下文各V2–V6数值是历史标定记录。

刚度、阻尼和速度上限取 M2Plan 第 5.2 节的初值。平移阻尼按等效质量 2 kg、阻尼比 1 得到 49 N·s/m；旋转按 0.02 kg·m² 得到 0.8 N·m·s/rad。这些是仿真调参尺度。

力矩变化率保持 2000 N·m/s。三个 `q_torque_poses` 上关节 2 的重力偏置大约是 35.3、14.7 和 42.1 N·m。100 N·m/s 会在接管时超过 0.5 rad/s。本轮接管代表轨迹从真实零力矩开始，用的是第一个 `q_torque_poses`。1 ms 下最大关节速度 0.162 rad/s、最大力矩 37.44 N·m；0.5 ms 下是 0.165 rad/s 和 37.53 N·m。两者都低于 0.5 rad/s。2000 N·m/s 是使接管留在关节速度门槛内的候选值，不是人体安全阈值。完整记录在 `outputs/m2/acceptance/m2-fix-v2/calibration.md`。预测关节速度上限仍是 0.4 rad/s，实际关节速度门槛仍是 0.5 rad/s。

腕部补偿使用编译后的工具子树质量 0.08 kg。`mj_objectAcceleration` 在静止时给出向上的 9.81 m/s²，这是比力；坐标加速度等于该读数加上 `opt.gravity`。减去 `m(g-a)` 后，空载残余在 0.02 N / 0.002 N·m 以内。食物质量不进工具模型，勺上食物会留下约 0.03 N 的载荷。

`hybrid_normal_force.enabled` 为 false。混合法向力没有做三种弹簧的条件验收，不能写成已通过。

工作空间盒子是起始 TCP 周围 50 mm，只覆盖局部测试，不代表完整喂餐空间。

V3 接触代表案例不再用 0.02 m/s 一直顶到弹簧面。那样会在接触瞬间打出大约 4.2 N 和 4.8 N 的 A/B 峰值，差 0.58 N，超过 `max(0.1*max(a,b), 0.02 N)`。夹具仍在 `y=-0.120`。现在先以 0.008 m/s 沿 −Y 接近，接触后改为 0.002 m/s 继续压入，并在法向力不低于 0.15 N 且已接触 80 ms 后切到 ACQUIRE，过渡的 0.2 s 里保持这路慢压。正式时长因此从 1.2 s 冻结为 2.0 s，否则接触和增益过渡放不进窗口。0.1 N 只是夹具里“确实还压着”的前提，不是人体安全阈值。

释放代表案例里，0.04–0.1 s 的 −5 N 反向力还没让沿 +X 的滞后连续超过 2 mm 达 10 ms，受阻标志不会出现。现冻结为：0.02 s 起给 +X 0.05 m/s，0.04 s 起给 −X 3 N，受阻后把命令清零，再用 1.2 s 把外力线性撤到 0。撤完后的时刻才是释放时刻，总时长冻结为 2.5 s，满足释放后再记录 1.0 s。这是慢撤载回归，不代替快速撤载，也不是 M2Plan 的 2 s 挡面试验。

快速撤载使用同一姿态、同一 +X 命令和同一 −X 3 N，时长仍是 2.5 s。受阻被识别后的下一个控制周期把命令和外力同时清掉，不再等弹簧误差消完。计分从 `unload_start` 起，并同时报告 `force_zero` 窗口。正式九例里最差的 TCP 线速度峰值是 0.0134 m/s，额外 +X 位移是 1.48 mm，0.8–1.0 s 稳定段线速度 0.00119 m/s、角速度 0.00458 rad/s。seed 0 的 A/B 撤载起点相差 0.5 ms。记录在 `outputs/m2/acceptance/m2-fix-v4-r3`。

V5 的增益合格不再相信轨迹自报的档位。期望 K/D、active、target 和过渡标志由案例初始阶段 TRANSPORT 与逐区间 phase 重建，0.2 s 过渡的第一行已经走了一个 dt。gear 案例还要有与实际终值一致的 `gain_complete`。释放后的零命令和零外载按六维分别核对，从首次归零一直检查到最后一个控制区间；0.5–0.6 s 再施加 −X 3 N 记为 `external_reloaded`。慢卸载的 1.2 s ramp 仍是合法非零外力，归零之后重新加载同样失败。V5 正式包是 `outputs/m2/acceptance/m2-fix-v5-r2`。

V6 把零命令也送进同一套关节投影。限位内 0.04 rad、历史指向外侧时，投影后的该轴预测速度为 0，执行状态仍是 `zero`，Guard 保持 RUNNING。远离限位的零命令按 0.25 m/s² 从 0.01 m/s 减到 0.00975 m/s，不是硬停。`rho <= 0.01` 在同一区间锁存 `singularity` 并用姿态阻尼 1 N·m·s/rad 制动。静止奇异姿态、关节 2 速度 0.03 rad/s 时，约 0.610 s 进入并保持不超过 0.02 rad/s；从 rho 略高于 0.01 的姿态以约 0.08 rad/s 靠近奇异区时，故障在 0.146 s，0.389 s 时已经满足 0.5 s 内降到 0.02 rad/s 并保持 0.2 s。这些门槛没有放宽。慢释放的计分从 `unload_start` 起检查 0–0.5 s 的速度、差分和额外 +X，并检查整段 ramp 的线速度；`force_zero` 之后才检查 0–0.5 s 和 0.8–1.0 s。仍落在 1.2 s ramp 内的 0.8–1.0 s 只记为 `diagnostic_during_ramp`，`passed` 为 null，不算静止通过。seed 0 的 A：blocked 0.148 s，unload 0.149 s，force_zero 1.349 s；unload 后 0.5 s 线速度峰值 0.017865 m/s，ramp 内 0.8–1.0 s 诊断峰值 0.009460 m/s。0.03 m/s、5 mm、0.005 m/s 和 0.05 rad/s 没有改。快速撤载仍从两个起点做完整瞬态和稳定窗。正式包是 `outputs/m2/acceptance/m2-fix-v6-r2`。
