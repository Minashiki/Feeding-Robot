# M2 参数说明

刚度、阻尼和速度上限取 M2Plan 第 5.2 节的初值。平移阻尼按等效质量 2 kg、阻尼比 1 得到 49 N·s/m；旋转按 0.02 kg·m² 得到 0.8 N·m·s/rad。这些是仿真调参尺度。

力矩变化率保持 2000 N·m/s。三个 `q_torque_poses` 上关节 2 的重力偏置大约是 35.3、14.7 和 42.1 N·m。100 N·m/s 会在接管时超过 0.5 rad/s。本轮接管代表轨迹从真实零力矩开始，用的是第一个 `q_torque_poses`。1 ms 下最大关节速度 0.162 rad/s、最大力矩 37.44 N·m；0.5 ms 下是 0.165 rad/s 和 37.53 N·m。两者都低于 0.5 rad/s。2000 N·m/s 是使接管留在关节速度门槛内的候选值，不是人体安全阈值。完整记录在 `outputs/m2/acceptance/m2-fix-v2/calibration.md`。预测关节速度上限仍是 0.4 rad/s，实际关节速度门槛仍是 0.5 rad/s。

腕部补偿使用编译后的工具子树质量 0.08 kg。`mj_objectAcceleration` 在静止时给出向上的 9.81 m/s²，这是比力；坐标加速度等于该读数加上 `opt.gravity`。减去 `m(g-a)` 后，空载残余在 0.02 N / 0.002 N·m 以内。食物质量不进工具模型，勺上食物会留下约 0.03 N 的载荷。

`hybrid_normal_force.enabled` 为 false。混合法向力没有做三种弹簧的条件验收，不能写成已通过。

工作空间盒子是起始 TCP 周围 50 mm，只覆盖局部测试，不代表完整喂餐空间。
