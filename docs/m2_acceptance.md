# M2 full-v5 验收

`validation/m2/spec.py` 定义完整 302 类矩阵，标定种子 0–2 共 2718 条轨迹，正式种子 3–8 共 5436 条轨迹。A/B/C、物理阈值及混合力关闭配置保持冻结。测试清单 `tests/m2_full_nodeids.json` 与正式反例清单分别核验，不能用测试总数代替覆盖。

## 模块与证据

- `provenance`：输入哈希、配置快照、初态、solver、执行身份与测试记录。
- `reference_checks`：解析任务目标、独立速度/约束/积分/增益重建。
- `physics_checks`：运动学、动力学、传感链与工具惯性补偿重建。
- `contact_checks`：独立接触许可、坐标转换、作用侧与关于 TCP 的净 wrench。
- `checks`：结构筛查及单例评分；`package`：包完整性、配对、趋势与唯一放行判定。
- `runner`：通过公开入口采集；`negatives`：真实副本变异；`legacy`：fixes-v6 只读适配。

每条轨迹的状态数组长度为 N+1，控制区间和步后 F/T 数组长度为 N。`t/tick` 来自真实状态；`p_ref_before/r_ref_before` 是进入控制区间前的参考，`p_ref/r_ref` 是本区间计算结果。`command_times` 保存发布时间和有效期，取消后两个值为 -1。`candidate_twist/beta/v_hist`、参考校正与约束原因支持独立重建。步前中止不增加控制区间或伪造物理样本。

接触 offsets 分隔每个步后样本，frame 的行是接触轴在世界系的方向；`contact_wrench_world` 保留世界系六维向量；完整 `contact_wrench_contact` 前三维是力、后三维是接触矩，世界向量由 frame 转置变换。该 wrench 作用于 geom2，geom1 取反。工具外部接触按所有权求和，并加上同刻施加外载；关于 TCP 的矩包括力矩臂。`tool_acceleration/arm_acceleration` 保存步后加速度，独立 Jacobian 差分及刚体惯性公式校验工具补偿。代数与同刻物理一致性使用 1e-7 容差，不扩大既有力/矩预算。

full-v3 及更早报告保留历史诊断意义，不能补写字段成为 full-v5 正式证据。

## 契约覆盖

| 契约 | 正常证据 | 独立检查与反例 |

| T03、T12–T14 | 公开入口、上电/运行/停车/reset | 步前异常不推进、阶段非法无副作用、首故障不覆盖 |

| T06–T07 | 工具静动态补偿、外力/矩、食物承载 | 原始 F/T、COM Jacobian/惯性重建、净载荷平衡 |
| T08–T11 | 三种弹簧、刚度对照、受阻释放、脉冲 | 力平衡、恢复窗口、峰值、冲量 |

## 运行与恢复

所有动态运行使用 `python -m feedingrobot.scripts.m2_limited --output <资源记录目录> -- <命令>`；采用 feedingrobot 环境，单 worker，单 CPU、MemoryHigh=4 GiB、MemoryMax=6 GiB、SwapMax=0。systemd 不可用则停止，不绕开限额。

依次运行 `validate_m2 --scope full --calibrate --output <全新标定目录>`，只读核验 `verify_m2_report --scope calibration --run <标定目录> --check-current-workspace`，然后运行 `validate_m2 --scope full --calibration <标定目录> --output <全新正式目录>`。正式生成器运行新的 M1、fixes-v6、必需回归、正式轨迹及真实副本反例，再由 package 完成封包。最后使用 `verify_m2_report --scope full --run <正式目录> --check-current-workspace` 独立复核。

暂存核验与标定核验始终不放行 M3。完成记录最后原子发布；中断时保留目录和失败证据，不手改 incomplete、版本或 m3_ready。修复源码/配置后使用新 run_id 重新冻结；不拼接旧正式轨迹。当前没有已完成的 full-v5 全矩阵，保持 `m3_ready=false`。

## 初态布置补充

触盘案例先完成 M2 IK，再用同一种子的原有八个食物候选，按顺序选择第一个无非法接触的布置。原始 M1 reset 状态与最终 M2 初态分别保存；`food_placement_attempt` 记录选中序号，离线在固定最终机械臂姿态下重建候选合法性，不能跳候选或换种子。该修复处理 IK 后餐具柄与食物初始穿透，不改变模型、碰撞门槛或运动参数。

实施期间在回归的真实副本流程中已查看种子 3、4，种子 4 暴露初态穿透；后续全矩阵结果必须披露这一事实，不能将全部 3–8 种子称为从未查看过的保留集。

接触/穿透故障案例还必须在预定 tick 保留完整注入接触（ID、位置、距离、frame、零 wrench），首故障摘要不能替代该原始见证。删除见证触发 `contact_stimulus`。

`external` 记录区间开始时的目标施力；`external_body_com_before` 与 `applied_wrench_com` 分别记录施力前质心和本次实际施加的世界系质心 wrench。MuJoCo 在区间中保持质心力矩，步后核验使用步后质心换算到 TCP，不能直接沿用步前世界施力点。代数转换仍使用既定数值一致性容差。实际运动差分与工具惯性补偿的交叉检查沿用已有力/矩误差预算。

## 带载运动与受阻进展（full-v5）

在原反向投影力 >0.3 N、参考领先 >2 mm 候选条件上，增加过去 20 ms 实际位置净推进确认；受阻轴为当前补偿力的反方向。该轴平均速度≤有效命令轴向速度的20% 且持续 250 ms，或连续至少 10 ms 且轴向累计推进缺口≥1.5 mm，才抑制其正向候选速度，切向不删除。确认时将轴向参考领先回算至最多2 mm，记录 `block_correction_pos`；切向参考和姿态不重置。判定投影和相对速度基准使用有效上层命令，避免被上一拍抑制后的加速度历史反馈解除；最终裁切量仍来自整形后的候选。

命令轴向速度≤1 μm/s 不触发该分支，低速命令仍按相对进展判断，不用固定绝对速度阈值将所有低速运动判停滞。`block_progress` 每控制区间保存 `[世界系窗口平均速度x/y/z,窗口跨度秒,确认累计秒,累计推进缺口米]`；`blocked_now` 表示当前区间的受阻/偏差顶限处理，`blocked` 仍是曾发生的历史锁存。独立校验从步前实际 TCP 位置、命令、力与时序重新计算，不能信任记录的进展量。窗口不足不确认该分支；零命令、反转、档位切换、重锚、停止/上电/禁止与饱和暂停清窗口。解除不等待先运动；20 ms 饱和、100 ms 偏差顶限与每步硬限不变。

带载圆保持原两圈、半径10 mm、周期4 s及参考目标 RMS≤2 mm/峰值≤5 mm。实际目标只增加由案例已知恒力和冻结 FREE 刚度计算的固定柔顺偏移 `K⁻¹F_ext`；实际误差仍需 RMS≤2 mm/峰值≤5 mm，姿态 RMS≤1°/峰值≤3°，不拟合中心或相位，不删除载荷起始瞬态。原始偏差与硬约束、T07 F/T 预算照常检查。新增字段与契约使用 full-v5，新输入身份不能复用 full-v3 的通过证据。

正常 `loaded_circle/spring/press/stiffness` 案例不应进入受阻处理；出现本步受阻即以 `normal_motion_blocked` 拒绝，不能因剩余轨迹或力学指标通过而掩盖动作被抑制。真正受阻在 wall/定向故障案例验收；wall 必须有由进展不足确认的处理，只有偏差顶限兜底不算通过。

推进缺口仅在候选与欠进展条件连续成立时，按 `(有效命令轴向速度−窗口实际速度)×dt` 累加；条件中断及窗口重置同时清零，不是待补执行命令。full-v5 的 `block_progress` 为 N×6；旧开发 full-v4 的 N×5 不补字段升级。

## FREE跟踪参数版本

`m2-full-v5-tracking5`仅标定FREE平移K=330 N/m、D=40 N·s/m（原300/49），另将现有上电阻尼倍率从8标定为12，其余控制参数不变；数组schema仍为full-v5。当前full期望增益独立冻结；fixes-v6前置按绑定输入哈希的控制配置版本选择330/40或原300/49，历史默认契约不变，不从轨迹自报D推导期望。改版本/参数快照而不匹配输入身份必须拒绝。旧full-v5包保留其源码/配置身份，不以格式兼容替代本版本验收。

解析运动失败同时记录`rms`、`maximum`、各自门槛及实际触发的`metric/observed/limit`；RMS超标但峰值通过时明确报告RMS，门槛及原错误码保持。第12节跟踪专项须新冻结并完整重做S5；S5通过也保持`m3_ready=false`，完整S6另行验收。

新增`damping`真实副本反例将当前轨迹的FREE阻尼伪造为旧49，重算文件哈希和回执后仍须由`gain_d`拒绝；原47类反例均保留。

最终跟踪候选还将`power_on_damping_scale`从8标定为12：该现有倍率仅在POWER_ON作用于六维阻尼，正常运行退出该倍率；FREE基值330/40、其他档位及旋转基值如表，STOP独立阻尼12不变。上电阶段实际旋转阻尼也随倍率增加，必须一并通过姿态、速度与力矩限制。失败中间候选按各自冻结源码复核，当前检查器仅承诺原正式300/49与最终330/40版本契约。

full独立增益检查将POWER_ON倍率冻结为12，正常运行倍率仍1，停止增益仍0；不读取日志自报倍率构造期望。新增`startup_damping`真实副本反例，在保持轨迹首个上电区间将六维阻尼伪造成旧倍率8，重算哈希与回执后仍必须命中`gain_d`。原47类反例与新增正常阻尼反例保留，总计49类。screen-005因尚未同步独立倍率而被gain_d拒绝，原日志保留，不能计为通过。

## S5验收补齐：入口、受阻事件与保持段稳态力

公开核验入口使用 `spec.SCHEMA` 分派当前full格式；不支持的旧格式和未知格式明确拒绝，fixes-v6仍走历史入口。标定成功不放行M3，错误scope也不能保留通过结论；CLI与包核验器采用同一结果。

`check_reference_path` 返回失败列表和独立重建的首次事件时间。`blocked_confirm` 是原始TCP进展、命令、力、参考领先及冻结窗口/确认条件首次成立的控制区间起点 `t_k`；不是历史blocked标志，也不要求回算量非零。硬墙必须有该确认且对应区间执行受阻处理，偏差顶限不能替代。A/B、A/C对该必需事件应用原20 ms上限。

`spring/press` 的 `force_mean` 改为5.25–6.25 s保持段腕部补偿合力模长均值，`contact_force_mean` 仍为同段法向接触力均值。两项分别进行A/B、A/C比较，差值上限均为max(较大绝对值的10%，0.02 N)；退出段零力不能代替保持段。缺保持窗口、缺适用指标或非有限值均拒绝。其他案例窗口、全程峰值/冲量、弹簧平衡和刚度趋势保持。

原49类真实副本反例保留，新增 `blocked_force_evidence`（清除物理力证据而保留受阻日志）和 `steady_contact_pair`（只翻倍保持段接触载荷），分别必须命中 `wall_progress_blocked` 和 `convergence:contact_force_mean`；文件哈希/回执重算，源包保持不变。缩小矩阵集成测试及前置stub不是S6证据。

本轮实施范围为上述三项及S5复验，完成后停止，S6未启动、`m3_ready=false`。控制运行链、参数、物理资产和原门槛不变。依赖变化及时同步 `requirements.txt`；本轮无需新增依赖。
